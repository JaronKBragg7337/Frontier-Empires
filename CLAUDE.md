# Claude Instructions for Frontier Empires

Before doing **anything** in this repository, read in this order:

1. `AGENTS.md`
2. `docs/UNIVERSAL_THREEJS_HIGH_FIDELITY_STANDARD.md`
3. `docs/FRONTIER_EMPIRES_SPEC.md`

Do not plan, generate assets, refactor, simplify, or implement gameplay before reading those files.

The Universal Three.js High-Fidelity Standard is mandatory. Browser/Three.js constraints are engineering problems to solve with architecture, LOD, streaming, workers, instancing, compression, and optimization — not reasons to lower the target.

The project does not use Claude or any other AI model as a runtime dependency. Model identities are game data and imagery; Frontier Empires owns the simulation.
