# Model portraits

This folder is reserved for the images/faces used to represent model civilizations.

The real AI models do not run inside Frontier Empires. A model is represented by:

1. its registry record in `src/data/models.ts`
2. an optional image/portrait stored here
3. a derived `CivilizationProfile` generated by the capability mapper
4. persistent world/history state stored separately from the model's measured data

## Adding a future model

1. Add a legally usable image such as `gpt-next.webp` to this folder.
2. Add a new `ModelRecord` in `src/data/models.ts` and set `image: './models/gpt-next.webp'`.
3. Enter measured metrics only when a source exists; preserve benchmark version and measurement date.
4. Leave unknown data unknown or mark temporary game assumptions as `inferred` / `fictional`.
5. Do **not** add model-name-specific behavior to the simulation.
6. Run the registry validator/build.
7. In the later succession UI, choose whether the model is a successor, branch, ally, rival, or independent civilization.

A new release should be able to change the face and capability profile of the war without erasing the story that already happened.
